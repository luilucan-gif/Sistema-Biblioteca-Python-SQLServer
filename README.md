# Sistema de Biblioteca Universitaria - Python y SQL Server

Sistema de gestión para una biblioteca universitaria desarrollado en Python y conectado a una base de datos Microsoft SQL Server.

## Descripción

Este proyecto permite administrar información de una biblioteca universitaria mediante una aplicación desarrollada en Python que se conecta a una base de datos SQL Server.

El sistema cuenta con un menú interactivo desde el cual se pueden visualizar, registrar, actualizar y eliminar datos, además de realizar consultas relacionadas con préstamos y usuarios.

## Funcionalidades

- Visualización de registros de diferentes tablas.
- Registro de nuevos datos.
- Actualización de información existente.
- Eliminación de registros.
- Consulta de préstamos realizados.
- Consulta de préstamos atrasados.
- Búsqueda de libros por título.
- Consulta de préstamos por usuario.
- Visualización del historial de préstamos.
- Conexión entre Python y Microsoft SQL Server.

## Tecnologías utilizadas

- Python
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- pyodbc

## Estructura del proyecto

- `biblioteca.py`: contiene el menú principal y las funciones para gestionar la información de la biblioteca.
- `conexionBD.py`: contiene la configuración utilizada para establecer la conexión entre Python y SQL Server.

## Objetivo

Aplicar conocimientos de programación en Python y gestión de bases de datos mediante la integración de una aplicación con Microsoft SQL Server.
